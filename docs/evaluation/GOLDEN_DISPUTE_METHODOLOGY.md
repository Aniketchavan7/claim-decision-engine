# Evaluation Benchmark: Golden Claim Dispute Dataset Methodology

## 1. Benchmark Scope
The golden dataset consists of 50 calibrated complex claim cases designed to challenge RAG clause retrieval, proportionate room rent caps, pre-existing condition (PED) exclusion limits, and multi-agent arbitration consensus.

## 2. Metric Standards
- Label Match Accuracy: Target $\ge 95\%$
- Policy Citation Precision: Target $\ge 98\%$
- Zero False-Positive Approvals on Statutory Exclusions
